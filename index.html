GTA Clipper

GTA Clipper es una herramienta de escritorio de uso personal que crea clips verticales de transmisiones y los publica en mis propias cuentas de YouTube, TikTok e Instagram.

Política de privacidad

La aplicación funciona solo en mi computadora. Usa el acceso a YouTube únicamente para subir videos al canal que autoriza el usuario y leer el nombre del canal.

Los permisos (tokens) se guardan cifrados en la computadora del usuario y no se envían a ningún servidor propio ni a terceros. No se recopilan, venden ni comparten datos personales.

El acceso se puede quitar en cualquier momento desde https://myaccount.google.com/permissions.

El uso de datos de las API de Google cumple con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.
